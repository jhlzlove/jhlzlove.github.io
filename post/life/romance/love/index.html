简单的缘起

12.17 和平常一样的下午，自己按捺不住枯燥的学习，就开启的游戏时光，没想到的是，接下来的时光中因为有她而变得更加生动多姿，这是我短暂的人生中最别致、最欢喜的时光，也是我以前从未有过的体验。

我喜欢她，喜欢和她一起聊天的时光，喜欢听她说一些碎碎念…从无关风月、单纯的喜欢到后来一厢情愿的愛上她，每一次我都很享受和她聊天的感觉，现在回过头来想，如果时间能定格该有多好。不过，人生总是遗憾造就美。这次，也不例外……

别样的欢喜

一旦沉浸在自己喜欢的事情中，时间往往在不知不觉中流逝。

我们加了微信，互相打了招呼，和我工作时添加其他人的时候差不多。然而没想到的是，她居然主动联系我，还是给我打的电话。😱，当时的心情！！！怎么说呢，惊喜+疑惑！对，是的，我很疑惑，从来没有人这样和我聊过。

那虽然是我们第一次聊天，但是我们天南地北，日月星辰，无所不谈，想法也是天马行空。一向不是很健谈的我在她面前居然意外的没有成为话题终结者。额，或者说她很健谈？尽管大部分时间都是她在说，我在听。

后来的一个月，在她有时间的时候我们总是一起聊天，或吐槽世界上的事情；或一起 emo；或者是她 emo，我安慰她，虽然她知道大道理的比我还多喽……就这样，慢慢的，我不由自主，内心疯狂的感觉自己愛上了她，很明显，这是我的自作多情。我忽然想起，曾经也有相似的经历，只是这次终于到我了。或许人就是这样的感情动物吧！很多不敢在熟人面前说的话，我却能在她面前毫无保留的说出来。

人的思想和认识总是随着经历的增长而逐渐改变，曾经自以为的想法或许在未来某个时间点，将会不攻自破。

我没有谈过戀愛，所以不知道愛情是什么样的。当时我想，于我而言或许就是如此吧。她对我没有异样的目光，总是和我分享的她的喜悦与忧郁，偶尔，还为我 指点迷津。现在想来，当时那种单纯的快乐真好。

{% timeline %}

人生的第一次戀愛的感觉，第一次吃醋，第一次和女孩长谈…不曾有过的体验，那时都经历了一遍。仿佛她是上天派来的使者，特意给我留下一段朦胧别致而又终身难忘的经历。

那个冬天，我们聊了很长时间，我说，我有点儿冷，等我先进被窝再说。 她说，哥哥缺一个我。 那一刻，我的心底有一丝暖意，慢慢扩散至全身。

{% poetry 锦瑟 author:李商隐 footer:唐 %} 锦瑟无端五十弦，一弦一柱思华年。 庄生晓梦迷蝴蝶，望帝春心托杜鹃。 沧海月明珠有泪，蓝田日暖玉生烟。 此情可待成追忆，只是当时已惘然。 {% endpoetry %}

她说，她很喜欢这首诗。但是我没有告诉她，我当时只读了两遍就记在了心里。

{% poetry 无题诗改编 author:佚名 footer:唐 %} 我生君未生，君生我已老。 我恨君生迟，__________。 {% endpoetry %}

……

她说，听我的声音感觉很年轻！但是呢，就是一个毫无感情的读词机器。我觉得也是，毕竟我不是 pro 的。哈哈哈哈。

她说，人不能过于自恋。我立马就想到了当时自己的自作多情、一厢情愿。

我说，我不想活太长时间，40 岁左右就可以了，然后死亡。 她说，我也是哎，活着就很累。 我说，这花花世界你不想再多看看吗？还有很多帅哥呢！八块腹肌的哦！ 她说，想啊，但我是不婚主义者。我只希望早点儿退休。

我不知羞耻的问她，旅游能不能带上我，端茶递水、收拾行囊我统统在行滴！

我喜欢听她感冒时的声音，嗲里嗲气，哈哈哈哈哈哈哈哈哈~

她说她想上楚晚宁。

她告诉我得不到才是白月光，而很多人得到后就成了朱砂痣。

有两次做梦梦到了她，梦中我对她说，我想抱抱她，她同意了，后来续梦再也续不上了。

她的配音配的越来越好了。

我喜欢她那适时而又恰当的撒娇，好可愛！

她说我们打雪仗，然后给我发了一个图片，我一看，好家伙：巨大的玻璃球！

她养了一只小兔子，胖呼呼的，貌似很不听话，因为总是到处乱跑。

推荐给我的洗发水我很喜欢，对油性头很有用耶！

他朝若是同淋雪，此生也算共白头。

她说以后想开一家配音工作室，我在想我要不要学学修音？？？

不曾想某一次脱口而出的话竟然一语成谶，眨眼间我们就到了最后要分别的时刻，我的心里时不时就是空落落的。我也想不明白自己为什么会有这种感觉，难受？好像是的。忽然就理解了王遗风的那句话“丢了你，赢了这世界，又如何？”是多么的凄凉。

人生路上，下一站陪你一起前行的或许不是同一个，而是另一个。但是大概我们印象最深的，还是第一个带给我们回忆的那个人吧。随着时间的沉淀，那将成为 最美好 的欢喜，也就是她曾说过的白月光。

“有些故事 还没讲完 那就算了吧” 至此我们的同行的旅途已经悄然结束 感谢一路相伴 祝福一生平安 留一份空白 随时浓墨重彩 {% endtimeline %}

此生识君，生死无悔！

瑰丽的谜题 何必苦苦追寻

驰隙流年，恍如一瞬星霜换。我不知道自己能够记多久和她之间的小故事，也不清楚我们是否还有说话的机会。不过，当时有她，和我，已然足够。

祝福她有美好的未来，有精彩的故事，希望她学业有成，考的全会，蒙的全对，可以顺利进入自己喜欢的学校学习，同时我也无比希望未来有一天，她会把她的人生故事一一讲给我听。

某年某月的某一天，你是否也会把我这傻瓜想念。
