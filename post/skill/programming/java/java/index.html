浪子没有深究过底层，也没有什么高大上的使用经验，只有一些浅显粗鄙的认知，按照自己的想法和行文表述出来，嗯，就这样

浪子的是学 Java 入行的，尽管这门语言有很多的历史包袱导致现状并不太好，但我还是非常感谢这门语言的，毕竟它也算是我的互联网启蒙老师。不知道自己能坚持到什么时候，总得留下一些东西以供后面回忆。

有关 Java 的文章比较乱，因为 Java 体系过于庞大，早期的总结放到现在可能不适用，而且也不是很好改，如有内容错误以及过时，将是很正常的事情。

从单体架构到前后端分离架构再到微服务架构，每一种都是为了解决新的问题而成就的，所以在编程语言中，问题与解决方案往往成双成对，编程领域百花齐放，各有优劣也是因此。加以作者大大身处不同业务领域，最终造就的框架也适用于不同的领域，脱离自身业务选择框架犹如不切实际的想法，为用而用是很多中小型企业的通病。但是毫无疑问，大家都是想提升自己，这是正常的，大家都喜欢优秀的人，也都想成为优秀的人。
